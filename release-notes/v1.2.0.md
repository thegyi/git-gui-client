# Git GUI Client 1.2.0

## Highlights

- **Remote-aware tag management:** see whether tags exist locally or on the selected remote, push local tags, and delete tags from both local and remote repositories. Remote-only tags can also be deleted.
- **Safer Git actions:** destructive actions use native confirmation dialogs in the desktop app, and cancelling leaves the operation untouched.
- **First-push setup for new branches:** pushing the current branch to a selected remote configures its upstream.
- **Workflow fixes:** improve branch actions, preserve stashes when a drop is cancelled, correct submodule path and discard handling, and improve recovery-panel layout.

## Downloads

Linux (`.deb`), Windows (`.msi`), and macOS (`.dmg`) installers are attached to the GitHub release as the build workflow completes.
